# Dashboard UI

A static project-management workspace demo with dashboard, tasks, calendar, analytics, team, settings, and help views.

## Run locally

From the repository root, start a static server:

```bash
python -m http.server 8080
```

Then open http://localhost:8080.

## Contents

- `index.html` — main entry point
- `assets/` — compiled JavaScript and CSS
- `favicon.png` — Dashboard UI favicon
- `fonts/` — bundled font stylesheet and font files

This is a static front-end demo; no backend service is included.
